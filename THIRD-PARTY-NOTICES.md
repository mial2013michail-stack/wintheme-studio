# Сторонние компоненты и товарные знаки

## Код и графика

WinTheme Studio не содержит сторонних NuGet-пакетов, библиотек и графических материалов.
Весь исходный код написан для проекта. Все обои, иконки, эмблема и элементы интерфейса созданы
оригинально и не являются копиями чужих работ.

## Среда выполнения

Опубликованная сборка является self-contained и включает среду выполнения .NET и Windows
Desktop Runtime. .NET распространяется по лицензии MIT:

- https://github.com/dotnet/runtime/blob/main/LICENSE.TXT
- https://dotnet.microsoft.com/

При сборке из исходников используется установленный .NET SDK; отдельные пакеты не
загружаются.

## Товарные знаки

Windows и Windows 11 — товарные знаки Microsoft Corporation. macOS — товарный знак Apple Inc.
Ubuntu — товарный знак Canonical Ltd. Названия используются только для описания стилистики
профилей («в духе macOS», «в духе Ubuntu»).

WinTheme Studio не связан с Microsoft, Apple и Canonical, не одобрен ими и не распространяет
их логотипы, обои, шрифты или темы. Профили являются оригинальными настройками приложения.

## Шрифты

Интерфейс использует системные шрифты Windows (Segoe UI и его варианты), которые
предоставляются операционной системой и не поставляются вместе с приложением.
